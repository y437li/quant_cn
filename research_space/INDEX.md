# research_space/

Exploration. Imports only from `quant_cn`, defines nothing reusable; the package never imports it. `outputs/` is git-ignored.

## Folders
| Folder | Purpose |
|---|---|
| [`notebooks/`](notebooks/INDEX.md) | dated one-off notebooks, `YYYYMMDD_<topic>.ipynb` |
| [`prototypes/`](prototypes/INDEX.md) | throwaway UI and data prototypes that inform a plan's design |
| [`runs/`](runs/INDEX.md) | one folder per ad-hoc analysis, `YYYYMMDD_<topic>/`, logged in `RESEARCH_LOG.md` |

## Files
| File | Purpose | Contains |
|---|---|---|
| `RESEARCH_LOG.md` | one row per ad-hoc analysis: question, scripts, lake outputs, conclusion, follow-up (D-144) |  |
| `main.ipynb` | working notebook: adjusted prices + charts, PIT fundamentals, run history; run with make notebook |  |
